Mapa de Pontos Úteis do Campus

O projeto utiliza HTML5 e CSS3 para criar uma página web com o mapa de pontos úteis do campus, facilitando a localização e consulta de locais e serviços.

1 - Tema

Mapa de Pontos Úteis do Campus

A aplicação apresenta informações sobre diferentes locais do campus, permitindo que o usuário visualize os pontos, consulte uma lista de locais e veja detalhes de cada ponto.

3 - Seções da página

O projeto é dividido em três seções principais:

- Mapa

Apresenta uma representação visual do campus com a localização dos principais pontos úteis, como salas, laboratórios, biblioteca, cantina, banheiros, secretaria e outros espaços relevantes.

- Lista

Exibe uma lista dos pontos disponíveis no campus, permitindo ao usuário consultar os locais de forma organizada.

- Detalhe

Apresenta informações específicas sobre um determinado ponto selecionado, como:

* Nome do local;
* Localização;
* Descrição;
* Horário de funcionamento;
* Outras informações relevantes.

- Workflow

As regras utilizadas para branches, commits e integrações estão documentadas no arquivo WORKFLOW.md.

- Fluxo de desenvolvimento

1. Atualizar a `main`;
2. Criar uma branch;
3. Realizar alterações pequenas;
4. Criar commits semânticos;
5. Enviar a branch ao GitHub;
6. Revisar as mudanças;
7. Integrar na `main`.

- Repositório
Este projeto é versionado utilizando Git e hospedado publicamente no GitHub.

- Objetivo
O objetivo do projeto é desenvolver uma interface simples para facilitar a localização de pontos úteis dentro do campus.
